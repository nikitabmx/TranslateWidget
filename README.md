# TranslateWidget

Маленькое нативное macOS-приложение в menu bar, которое по настраиваемому
глобальному хоткею (по умолчанию **⌥⌘T**) открывает всплывающую панель в стиле
Spotlight с **собственным** интерфейсом перевода. Курсор сразу в поле ввода —
печатаешь и видишь перевод вживую.

## Возможности

- Живёт в menu bar (иконка 🌐), без иконки в Dock.
- Настраиваемый глобальный хоткей (по умолчанию **⌥⌘T**) — открыть/закрыть из
  любого приложения. Меняется в «Настройки…» (`⌘,` в меню иконки).
- Нативный UI: поле ввода + блок перевода, без веб-интерфейса Google.
- **Вкладки языков**: первая — «🔍 Detect» (автоопределение источника →
  системный язык, с выпадашкой выбора языка-цели), остальные — готовые пары
  RU↔EN, RU↔SR, EN↔SR.
- **Живой перевод**: переводит во время ввода, а при смене вкладки/языка сразу
  пересчитывает результат.
- **🔴 Голосовая диктовка**: слева вместо иконки — **красная кнопка записи**.
  Нажми — и от неё анимированно растёт **дорожка звуковой волны**, реагирующая
  на голос; «лишний» интерфейс (поле, выбор источника, статус) на это время
  скрывается. Нативное распознавание речи (Apple **Speech** + **AVAudioEngine**),
  по возможности **на устройстве** (приватно, без серверного лимита по времени).
  Распознанный текст **на ходу заменяет красную дорожку** и сразу переводится.
  Язык берётся из выбранного
  источника (для «Detect» — язык системы). **Esc** — отменить диктовку (вернуть
  как было), повторный **Esc** или **крестик** — закрыть панель.
- **Escape** или клик мимо панели — скрыть. Кнопка «Скопировать перевод».

## Движки перевода и LLM

В «Настройках» отдельно выбираются:

- **Переводчик** — кто переводит текст: Google (бесплатно, без ключа),
  Google Cloud, DeepL, ChatGPT (OpenAI) или Claude (Anthropic). Варианты без
  сохранённого ключа **дизейблятся** — сначала добавь ключ.
- **LLM** — какой LLM (OpenAI или Claude) отвечает за **исправление орфографии**
  (кнопка ✨) и «причёсывание» надиктованного текста. Само распознавание речи —
  нативное (macOS Speech).

**API-ключи** хранятся **локально и отдельно для каждого сервиса**. После ввода
ключа жми **Сохранить** — ключ валидируется запросом к провайдеру; при успехе он
прячется звёздочками, а рядом появляется кнопка **копировать**. Бесплатный Google
работает без ключа. Вся логика — в `Sources/TranslationService.swift`.

## Сборка

```sh
cd ~/DevProjects/TranslateWidget
./build.sh
```

Соберётся `TranslateWidget.app` рядом со скриптом (компилируются все файлы из
`Sources/`).

## Запуск

```sh
open ./TranslateWidget.app
```

После запуска в правом верхнем углу появится иконка 🌐. Нажмите хоткей.

## Автозагрузка (по желанию)

Проще всего: правый клик по иконке 🌐 → **«Launch at Login»** (галочка). Это
регистрирует приложение как объект входа через `SMAppService` — снять можно тем
же пунктом.

Альтернатива вручную: **Системные настройки → Основные → Объекты входа → +** и
добавьте `TranslateWidget.app`.

## Настройка

- **Хоткей**: меню иконки → «Настройки…» → задайте сочетание (применяется сразу,
  сохраняется между запусками).
- **Переводчик / LLM / API-ключи**: там же, в «Настройках» (см. раздел выше).
- **Языки-цели в выпадашке Detect**: массив `targetCodes` в
  `Sources/TranslatePanelController.swift`.
- **Языковые пары на вкладках**: массив `LanguagePair.all` в
  `Sources/LanguagePair.swift`.

## Структура

| Файл | Назначение |
|---|---|
| `Sources/main.swift` | `AppDelegate`, menu bar, точка входа |
| `Sources/HotKeyManager.swift` | Глобальный хоткей (Carbon) + хранение |
| `Sources/ShortcutRecorderView.swift` | Запись сочетания клавиш |
| `Sources/PreferencesWindowController.swift` | Окно настроек |
| `Sources/TranslatePanelController.swift` | Панель: вкладки, ввод, перевод, диктовка |
| `Sources/TranslationService.swift` | Запрос перевода |
| `Sources/DictationManager.swift` | Распознавание речи (Speech + AVAudioEngine) |
| `Sources/WaveformView.swift` | Анимированная звуковая волна диктовки |
| `Sources/PlaceholderTextView.swift` | `NSTextView` с плейсхолдером |
| `Sources/LanguagePair.swift` | Описание языковых пар |

## Примечания

- Приложение собирается локально и подписывается ad-hoc подписью; `build.sh`
  также снимает карантинный атрибут (`xattr -dr com.apple.quarantine`), поэтому
  на этой машине Gatekeeper запуску не мешает.
- **«Не удаётся проверить разработчика» при переносе на другой Mac.** Это
  Gatekeeper: ad-hoc подпись не доверена на чужой машине. Варианты:
  - на принимающем Mac: правый клик по `.app` → **Открыть** → **Открыть**
    (один раз), либо **Системные настройки → Конфиденциальность и безопасность →
    «Подтвердить открытие»**, либо в терминале
    `xattr -dr com.apple.quarantine /путь/TranslateWidget.app`;
  - «правильно» (без предупреждений у кого угодно) — нужен платный **Apple
    Developer ID** + **нотаризация** приложения. Без него предупреждение на чужих
    Mac неизбежно.
- При первом нажатии на микрофон macOS спросит доступ к **микрофону** и
  **распознаванию речи**. Если случайно отказали — включите вручную в
  **Системные настройки → Конфиденциальность и безопасность → Микрофон** и
  **→ Распознавание речи**. Для офлайн-распознавания язык можно заранее
  скачать в **Системные настройки → Клавиатура → Диктовка**.
