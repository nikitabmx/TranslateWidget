# TranslateWidget — установка

Небольшое приложение в строке меню macOS: всплывающий виджет для **перевода** и **исправления текста**. Открывается по горячей клавише **⌥⌘T** из любого приложения.

## Требования
- macOS 13 (Ventura) или новее.
- Mac на Apple Silicon **или** Intel — сборка универсальная.

## Установка
1. Открой **TranslateWidget.dmg** (двойной клик) и в появившемся окне перетащи **TranslateWidget** на папку **Applications**.
   Если у тебя архив `TranslateWidget.zip` — распакуй его двойным кликом и перетащи **TranslateWidget.app** в папку **Программы** (Applications).
2. Диск TranslateWidget после этого можно извлечь (⏏ в боковой панели Finder).

## Первый запуск (важно — сделать один раз)
Приложение не из App Store и без подписи разработчика Apple, поэтому при первом запуске macOS его заблокирует. Это нормально. Обойти нужно только один раз:

**Способ 1 (проще):**
1. В Finder открой папку «Программы».
2. **Правый клик** (или Ctrl + клик) по `TranslateWidget` → **«Открыть»**.
3. В появившемся окне нажми **«Открыть»** ещё раз.

Если в окне нет кнопки «Открыть» (только «Отмена»): закрой его, открой  → **Системные настройки → «Конфиденциальность и безопасность»**, пролистай вниз и нажми **«Подтвердить открытие»** (Open Anyway), затем снова открой приложение.

**Способ 2 (через Терминал — если пишет, что приложение «повреждено»):**
Открой «Терминал» и вставь команду:
```
xattr -dr com.apple.quarantine /Applications/TranslateWidget.app
```
После этого открывай приложение обычным двойным кликом.

После первого успешного запуска приложение открывается как обычно.

## Где оно находится
- Значок **🌐** в **строке меню** сверху справа (рядом с часами). **Значка в Dock нет — это нормально.**
- Виджет открывается сразу после запуска и по горячей клавише **⌥⌘T** (Option + Cmd + T).
- **⌥⇧⌘T** (Option + Shift + Cmd + T) — скриншот куска экрана с переводом текста на нём.
- Обе комбинации можно поменять в **Настройках**.
- **Левый клик** по 🌐 — открыть/закрыть виджет. **Правый клик** — меню (скриншот с переводом, Настройки, Выход).

## Как пользоваться
- **Перевод** появляется сразу, по мере ввода. Справа — язык, **с которого** переводить (при открытии берётся из текущей раскладки клавиатуры), кнопка **⇄** (поменять языки местами) и язык, **на который** переводить.
- **Исправление текста** — чёрная кнопка **✨** справа: исправляет сам текст в поле ввода (под ним появится подпись, **⌘Z** — вернуть как было), а перевод ниже обновится. Рядом с кнопкой выбор манеры:
  - **Light** — только орфография, грамматика и пунктуация;
  - **Balanced** — то же + лёгкое улучшение читаемости;
  - **Formal** — строгий официально-деловой стиль.
- **Выделенный текст**: выдели текст в любом приложении и нажми **⌥⌘T** — он сразу окажется в виджете и переведётся (нужен «Универсальный доступ», см. «Разрешения»).
- **Скриншот с переводом**: нажми **⌥⇧⌘T** и протяни рамку мышью по тексту на экране или кликни в одном углу, а затем в противоположном (**Esc** — отмена). Откроется виджет: снимок прикреплён чипом, текст с него распознан прямо на Mac (без интернета) и сразу переведён.
- **Текст с картинки**: вставь картинку или скриншот (**⌘V**) в поле ввода или перетащи изображение на виджет — тоже станет чипом с распознанным и переведённым текстом. **✕** на чипе убирает картинку вместе с её текстом, клик по чипу — превью.
- **Enter** — перевести сразу, **Shift+Enter** — новая строка.
- Иконка справа над переводом — скопировать перевод.
- 🎙 Микрофон слева — голосовой ввод (диктовка).
- **Esc** или клик мимо окна — закрыть виджет.

## Ключи API
- Перевод по умолчанию работает через **бесплатный Google** — ключ не нужен.
- **Исправление текста (✨)** и перевод через **ChatGPT/Claude** требуют своего **API-ключа** (OpenAI или Anthropic). Введи его в **Настройках**: правый клик по 🌐 → **«Settings…»** (или `⌘,`).
- Это оплата по токенам с баланса API-аккаунта (доли цента за сообщение). Подписки ChatGPT Plus / Claude Pro для API **не подходят** — нужен именно API-ключ.

## Разрешения
- При первом использовании диктовки macOS попросит доступ к **микрофону** и **распознаванию речи** — нажми «Разрешить».
- Чтобы по **⌥⌘T** подхватывался выделенный текст, нужен **«Универсальный доступ»**: при первом нажатии macOS покажет запрос → **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** → включи **TranslateWidget**, затем нажми ⌥⌘T ещё раз. Без этого разрешения виджет просто открывается пустым.
- Для скриншота (**⌥⇧⌘T**) нужна **«Запись экрана»**: при первой попытке macOS покажет запрос → **Системные настройки → Конфиденциальность и безопасность → Запись экрана** → включи **TranslateWidget** и перезапусти приложение.

## Удаление
Перетащи **TranslateWidget.app** из «Программ» в корзину.

## Если что-то не так
- **«Не удаётся открыть программу…» / «повреждена» / «не удаётся проверить разработчика»** → это всё блокировка Gatekeeper. Самый надёжный способ — Способ 2 (команда `xattr` выше). На macOS 15 (Sequoia) можно также: запустить → получить блокировку → «Системные настройки → Конфиденциальность и безопасность» → «Подтвердить открытие».
- **После запуска не видно окна** → это нормально: приложение живёт в строке меню (🌐), окна и значка в Dock нет. Нажми **⌥⌘T**.
- **Старая/блёклая иконка в Finder** → это кэш значков, на работу не влияет.
